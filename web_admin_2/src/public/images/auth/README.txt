Thư mục này dùng để lưu ảnh banner cho trang đăng nhập admin.

Gợi ý:
- Đặt tên file cố định: `login-banner.jpg`
- Đường dẫn dùng trong giao diện: `/public/images/auth/login-banner.jpg`
- Kích thước nên dùng: khoảng 1200x900 hoặc tỷ lệ 4:3
- Định dạng nên dùng: `.jpg`, `.png`, `.webp`

Bạn chỉ cần chép ảnh banner vào đây, ví dụ:
- `web_admin_2/src/public/images/auth/login-banner.jpg`
